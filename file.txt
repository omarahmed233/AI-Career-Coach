TECH TARGET ROLE SKILL PROFILES
Purpose: Retrieval reference for comparing explicitly evidenced CV skills with a target role.

MATCHING RULES
- Retrieve the profile matching the supplied target role; use the job description first when one is available.
- Treat CORE SKILLS as common baseline expectations, not automatic requirements in every vacancy. Treat STACK-SPECIFIC SKILLS as conditional on the job description.
- Mark each skill MATCHED only when the CV explicitly names it or gives clear evidence of using or learning it in projects, training, coursework, or achievements.
- A related skill is PARTIAL only when it is genuinely transferable; do not claim it is equivalent. Otherwise mark NOT EVIDENCED.
- Never infer experience, proficiency, certifications, years, or skills from a title or from general knowledge.
- Return the CV evidence for every match. Keep role requirements separate from CV skills.
